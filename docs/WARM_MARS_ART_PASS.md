# ARES — тёплый промышленный Марс: первая арт-сборка

**2026-10-15.** Пользователь выбрал тёплый промышленный стиль и попросил прекратить добавление механик, заменить процедурный визуал готовыми решениями, дополнить его сгенерированными здесь изображениями. Реализован один цельный экран фермы/инженерного сектора с тем же поведением.

> **Продолжение:** [арт остальных отсеков](WARM_MARS_SECTIONS.md) добавляет три изображения/общие wrappers и navigation. Сведения о шести файлах ниже относятся к первой арт-сборке поля; текущий инвентарь — девять файлов.

## Что реально заменено

- Убраны процедурные горы/рельеф, градиентное небо CanvasTexture, шумовые PBR-карты и случайная расстановка скал в текущем field view.
- Убраны видимые `BoxGeometry`/`CylinderGeometry` для платформ, резервуара, энергоблока, насоса и климатического оборудования.
- Вместо них — готовые CC0 GLB Kenney Space Kit / Factory Kit / Nature Kit и Quaternius Ultimate Space Kit. Размещение, масштаб, материалы и instancing растений остаются кодом композиции, не генератором форм.
- Единственный примитив — **невидимая принимающая тени плоскость** `PlaneGeometry` + `ShadowMaterial`. Это технический shadow catcher, не нарисованная геометрия окружения/оборудования.
- Сцену окружает отдельная иллюстрированная панорама Марса. Это художественный 2.5D фон, не реально отсканированная местность и не доказательство географической точности.
- UI использует готовую бронзовую панель и изображения иконок вместо линейных значков оборудования/плоских карточек. Надписи, числа и все controls остаются live DOM.

## Композиция экрана

- Верхний компактный корпус-навигатор и hero с уже готовой картиной теплицы/Tuber‑9.
- Выбор того же поля по public key, прежние слои POTATO/SIM и карточки.
- Слева большая 3D-сцена на рисованном фоне, над ней четыре предметные ресурсные карточки.
- Справа отдельный приборный корпус: часы/ресурсы и вкладки **«Управление / Климат / Сервис»**. На desktop содержимое прокручивается внутри панели.
- Нижняя приборная дека: **«Телеметрия / Партии / Журнал»**; показана только одна вкладка, без длинной страницы всех таблиц сразу.
- После SIM-сбора/начала обработки автоматически открываются партии; новый сценарий возвращает телеметрию. Это только навигация, не новое правило расчёта.
- Мобильная композиция складывает секции вертикально, поля/панорама/иконки остаются реальными asset files. WebGL fallback использует готовый `plantation.webp`, не CSS-рисунок грядок.

Это стилизованная игровая композиция, не обещание фотореализма: исходная готовая геометрия сохраняет low-poly характер. Все новые картинки — отдельные ассеты, не плоский скриншот интерфейса с неработающими кнопками.
