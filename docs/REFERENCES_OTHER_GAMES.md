# Референсы: что берём из других игр и ассетов

**Дата проверки:** 2026-10-16. **Правило:** код чужих проектов не копируем, если лицензия не позволяет использовать его в закрытом коммерческом проекте. Из идей берём только механики, а не реализацию. Ассеты берём только под CC0 или MIT-совместимыми лицензиями, и каждый добавляем в `THIRD_PARTY_LICENSES.md`.

## Не проверено (нужна проверка перед использованием)

- `uzair-ashraf/farming-sim`, `devhitp/FarmSimulator`, `GP2P/FarmSimulator`, `bashfarm`, `EverCrops` — идеи по росту культур и офлайн-росту. Лицензии не открывались. Брать только механики, код не брать.
- Kenney (Space Kit, Space Station Kit) и Quaternius — заявлены как CC0. Проверить на странице пака перед загрузкой.
- `mars-sim/mars-sim` и `linuxlinks`-ссылка — Java-симулятор, только как источник идей.

## Что уже сделано по этим референсам

- Модели колонии и полей взяты из Kenney, Quaternius и Factory Kit (CC0), уже в репозитории и проверены по SHA-256 (см. `game/apps/web/public/models/*/manifest.json`).
- Для идей по росту и балансу референсы в код не переносились.

2. ~~Нужен ли нам баланс четырёх ресурсов из survive-mars~~ — **решено 2026-10-16:** четыре ресурса (вода, еда, кислород, энергия) встроены в модель колонии (коммит `3242b61`) вместе с CR. Код survive-mars (MIT) не копировался, только механика, поэтому уведомление не требуется.
