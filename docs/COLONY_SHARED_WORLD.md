# Общий мир колонии — спецификация этапа 1

Статус: **этап 1 в работе**. Ядро в движке реализовано (`colony/world/shared.ts`, тесты в
`test/shared-world.test.mjs`). Бэкенд (тики, таблицы, API) и клиент — следующие шаги. Все числа ниже
**предварительные**, для балансировки, не финальные.

## Решения владельца (2026-11-06)

- **Конкуренция**: месторождения и рынок (этап 1). Доска заказов, исследования и сезоны — следующие этапы.
- **Аренда участков в CR** за тик — основной сток CR из мира. Да.
- **Призы сезона**: только CR и косметика. POTATO не выплачивается, GO не требуется.
- **Разрушение построек других игроков**: запрещено. Конкуренция только через ресурсы и рынок.
- **Скорость мира** (не спрашивалось): по умолчанию один тик мира = одни игровые сутки, раз в сутки реального
  времени. Требует подтверждения.

## Ограничения, которые не меняются

- POTATO только сжигается и тратится только на стройку и ремонт (§47, §63). За токены нельзя купить
  CR, участки или товары для мира. Конкуренция остаётся игровой.
- Тик мира — системная запись в журнал. Порядок фиксирован: аренда → добыча → рынок. Одинаковые входы
  дают одинаковый результат.

## Механики этапа 1

| Механика | Правило | Тип |
|---|---|---|
| Участок | Месторождение: конечный запас, занимается за аренду. До 2 участков на игрока. | конкуренция |
| Аренда | 5 CR за тик. Не заплатил — участок освобождается. | сток CR |
| Добыча | Только на свой участок. До 50 кг за тик с месторождения. Истощается. | источник товаров |
| Рынок | Пакетный клиринг за тик. Цена = базовая × (1 + 0.5 × (спрос − предложение) / (спрос + предложение)), коридор ×0.5…×2. Базовые: лёд 3 CR/кг, картофель 4 CR/кг. | конкуренция |
| Комиссия рынка | 2% от оборота. | сток CR |

Заявки режутся до доступного: покупатель — по своим деньгам, продавец — по своему запасу. Так товар и CR
сходятся до копейки.

## Инвариант экономики

- **CR**: Σ изменений балансов за тик + приросты стоков (аренда, комиссия) = 0. Никакой источник CR
  в мире не создаётся.
- **Товары**: на рынке Σ изменений кг = 0. Товар появляется только при добыче.

Следствие: в этапе 1 общая сумма CR в мире только уменьшается (сток без источника). Это риск дефляции,
которому нужен баланс. Варианты: (a) источник CR через контракты (этап 2), (b) внешний покупатель по
фиксированной цене с дневным лимитом. Выбор — отдельным решением владельца.

## Этапы

- **Этап 0.** `world_id`, общая карта только для просмотра и таблица лидеров. Экономика не меняется.
- **Этап 1 (здесь).** Месторождения, аренда, пакетный рынок. Ядро реализовано и протестировано.
  Бэкенд: таблица состояния мира, системный тик, API `/api/colony-world/*`. Клиент: карта участков и рынок.
- **Этап 2.** Доска заказов (с решением по источнику CR) и исследования.
- **Этап 3.** Сезоны, мировые события. Призы — только CR и косметика.
