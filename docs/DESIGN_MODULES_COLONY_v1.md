# МОДУЛИ КОЛОНИИ — дизайн-док v1

Дата: 2026-10-14 · Ветка: `arena/41f71fb3-ares1` · Пилот: `game/apps/modules-prototype`

## 0. Одна фраза

Игрок собирает марсианскую станцию из модулей, станция становится живой системой
(энергия, вода, воздух, еда текут по связям), каждая постройка **сжигает 🥔 (BURN)**,
лишние ресурсы и призы **переходят** другим игрокам (**TRANSFER**).

## 1. Ядро цикла (1–2 минуты на решение)

1. Каталог модулей → выбираешь, чем занять клетку.
2. Постройка стоит 🥔 → списанная часть уходит в **BURN** (производство съело).
3. Модуль работает только в сети: соседство/кабели (adjacency) — «собираем модули».
4. Ресурсы колонии растут → уровень станции, наука, население.
5. Угроза (пылевой шторм, поломка) → выбор: аварийный протокол (**BURN**) или просить
   клана/соседа (**TRANSFER** из казны/игрока).
6. **Недельный спринт-билд**: общее семя карты + ограничение ресурсов → рейтинг
   энергоэффективности (output на единицу стоимости) → топы делят приз из казны
   (TRANSFER). Открытый вход — бесплатно (чек-лист, требование «бесплатный вход»).

## 3. Токен-потоки ($POTATO)

| Действие | Поток | Примечание |
|----------|-------|-----------|
| Постройка модуля | **BURN** (часть стоимости) | главный sink |
| Экспресс-стройка (ускорить таймер) | **BURN** | за геймплей, не за деньги |
| Аварийный протокол во время бури | **BURN** | по мотивам реальных данных NOAA/NASA |
| Покупка модуля/ресурса у игрока | **TRANSFER** | рынок колонии |
| Помощь клану / общий фонд | **TRANSFER** | синергия с механикой «общей зимы» |
| Приз за место в недельном спринте | **TRANSFER** из казны | payout по подписанному ваучеру |
| Открытый турнир | вход бесплатно | чек-лист требование |
| Вклад в общее исследование (наука) | **BURN** опционально | ускорение общей цели |

Реализация на devnet — через существующие `claim_achievement` / `grant_reward[_once]` +
backend-signed voucher (опция A, ранее утверждена): бэкенд считает рейтинг, подписывает
ваучер, клиент клеймит.

## 4. Арт-контракт («чтобы сходилось по пикселям»)

- 1 клетка = 1 юнит. Footprint всех модулей — целые размеры, snap-шаг 0.5.
- Ортогональная изометрия, фиксированный угол; масштаб единый (модуль ≤1×1×1.2).
- Палитра (`src/data/modules.js` → PALETTE): корпус `#ece7de`, ржавчина `#c86a3e`,
  панели `#2f4157`, баки `#b8c4c9`, акцент `#ff8a4c`, тилы `#6d655e`, фон `#2b2724`.
- Источник стиля: **Kenney CC0** (Modular Space Kit, Space Kit, City Kit Industrial,
  Factory Kit, UI Pack: Sci-Fi) — перекраска в марсианскую палитру вместо генерации.
- Генерация — только хвост: иконки, фоны меню, недостающие мелкие модели (воксельный
  пайплайн: целочисленная сетка). AI-3D «в стиль» не используется — риск рассинхрона.
- Автопроверка: меш не выходит за пределы клетки (тест bounding box).

## 5. Что делает это «настоящей игрой»

- Онбординг 60 сек (первые 3 модуля — подсказка с рукой).
- Дерево технологий модулей (лаборатория → следующие поколения: ядро, оранжерея-2).
- Буря-события по реальным данным Марса → аварийные протоколы (BURN).
- Сезонность на 28-дневных эпохах ARES-1: сезонные карты-семена, тематические модули.
- Джус: bounce-анимация установки (уже в пилоте), звук щелчка, пыль, подсветка портов.

## 4.5 Редкость модулей (обсуждение, v1)

Ступени: **Common → Rare → Epic → Legendary** (Базовый → Улучшенный → Экспериментальный → Легендарный).

**Что делает редкость:**
- **Визуал = кодировка**: Common — чистый бело-серый корпус; Rare — синие окна-акценты;
  Epic — медно-оранжевые + мягкое свечение; Legendary — золотые рёбра, аура, частицы.
  Цветовое различие заодно решает задачу марсианской палитры (база общая, редкость — различия).
- **Статы**: +15% выхода на ступень, но ×2–3 стоимость в 🥔 — редкость не даёт бесплатного
  преимущества (проверяется недельным спринтом по метрике «выход / стоимость»).
- **Экономика**: крафт = BURN, причём доля сжигаемого растёт по ступеням — редкость
  работает как sink; продажа/разбор редкого = TRANSFER (рынок колонии).

**Регуляторы, чтобы редкость оставалась редкой:**
1. Вероятностный крафт на верхних ступенях (Legendary60%): при провале часть материалов
   сгорает → доп. BURN, рост цены естественный.
2. Недельный/эпохальный квот производства (soft cap на28-дневную эпоху): после лимита
   смета 🥔 растёт автоматически (динамическая цена, без админов).
3. Сезонная ротация набора Epic/Legendary — старые остаются коллекционными.
4. Гарантированный «пол»: разбор возвращает частичную стоимость (без разгона инфляции).

**Источники:**
| Источник | Выдаёт | Поток токена |
|---|---|---|
| Лаборатория (наука ⭐) | чертежи Rare+ | вклад → опциональный BURN-ускоритель |
| Недельный спринт (топ-10) | Epic/Legendary-чертеж | TRANSFER из казны |
| Крафт | сам модуль | BURN (доля растёт со ступенью) |
| Рынок игроков | обмен редким | TRANSFER |
| Буря (реальные данные NOAA) | фрагмент Legendary | вход через аварийный протокол → BURN |

Античит: чертежи и владение считает сервер (gameops), сезонные награды — `grant_reward_once`.

## 6. Дорожная карта

- **M0 (текущий)** — пилот-визуал: сетка, 6 модулей, ресурсы, BURN на постройку. ✅
- **M1** — связность как правило: кабели требуются, энергия течёт по сети, idle-состояния.
- **M2** — токены devnet: burn-хук на постройке, казна спринтов, signed voucher → `grant_reward`.
- **M3** — недельный спринт: семя карты, серверный пересчёт рейтинга, лидерборд, 28-дневная эпоха.
- **M4** — буря/события (NOAA), дерево технологий, рынок игроков (TRANSFER), кланы.

## 7. Античит (M3)

Сервер — источник истины: клиент шлёт последовательность действий с семенем, сервер
пересчитывает экономику и рейтинг (как replay recompute из плана HexGL), подпись
выдаёт только сервер. Одноразовость наград — `grant_reward_once` на стороне программы.

## 8. Стек и размещение

Пилот: Vite + React 18 + three.js (ортого-изометрия, flat low-poly из примитивов —
внешние модели не нужны). Продукт: встраивается как активный режим поверх
`game/apps/web` (React-клиент), токен-слой — `game/programs/solana_potato` + gameops.
