## 2. «Одинаковое оформление на всём подряд»

1. **Ни одной главной панели.** `.pf-card` вешается на всё с равным весом — баланс POTATO, кнопка «Смена кошелька»,
   карточка ордера и переключатель языка выглядят одинаково весомо. Требование «одна явная главная панель на экран»
   сейчас не выполнено нигде.
2. **Одинаковые скобки и метка «МОДУЛЬ» на каждой панели S2.** `AresHullFrame` рисует одни и те же кронштейны
   (topBracket/bottomBracket/rightBracket), шильдик `plate: "МОДУЛЬ"` (skin default) на каждой панели шире 180px,
   одинаковый hazard-язычок справа и одинаковый бегущий огонёк по периметру → на экране 3–6 панелей с одинаковым
   «вниманием к себе».
3. **Три реализации «болтов»:** CSS `--ares-rivets-rust` (radial-градиенты в `.pf-card`), `RivetCorners` (компонент,
   **экспортирован, но не используется**), `fasteners` в SVG `AresHullFrame`.
4. **Янтарный glow-текст** `textShadow: '0 0 8–14px rgba(255,179,71,…)'` повторяется инлайном ~20 раз
   (Header, StatCard, SolHud, MissionLog, BuyFieldCard, OrderCard…) — неон-свечение текста, маркер «нейросетевого» UI.
5. **Два стиля LCD-показаний:** `.lcd-readout` есть только в `MarketScreen.StatCard`; балансы шапки и цифры Каюты —
   обычный `ares-mono` + text-shadow. Показания должны быть единым приборным стилем.
6. **Четыре разных StatCard:** `Header.StatCard` (amber-цифра + stencil-метка), `MarketScreen.StatCard` (icon + lcd),
   `StatsScreen.ConsoleStatRow` (консольная строка с LiquidBar), панели-«Ранг/Паёк» в Каюте. Четыре визуальных языка
   для одной сущности «прибор».
7. **Кнопки: 7+ несовместимых стилей.** Общий `Button.tsx` (glow/spring/scale) живёт только в `FieldCardVice` и
   `CreateOrderModal`; остальное самодельное: `gradient-gold` (Отгрузить), `market-filter-apply/reset`, лицензионные
   кнопки `var(--pf-gold)`, модальные `rgba(255,255,255,0.1)`, три инлайн-стиля покупки в `BuyFieldCard`,
   циановая `linear-gradient(135deg, var(--pf-teal), var(--pf-teal))` «Подключить кошелёк» (прямо цвет NeuroForge).
8. **Заголовки экранов в двух системах:** `pf-h1` (АГРО-ОТСЕК, КАЮТА) против сырых `h1 style={{fontSize:28}}`
   (СНАБЖЕНИЕ, ЖУРНАЛ МИССИИ) — разный шрифт/цвет/трекинг между экранами.

## 4. Токены и CSS-археология

- **Конфликт значений:** `tokens.css` объявляет `--ares-bio-green: #7CFF6B` (зелёный), `global.css` позже
  переопределяет его на `#FF2E93` (розовый) — «зелёный растений» в коде на самом деле розовый; имя врёт.
  Аналогично переопределяются `--pf-text-*`, `--pf-glow-green`, `--pf-grad-border*`.
- **5+ слоёв `:root`-«PASS»** в `global.css` (THICK STENCIL PASS → MASSIVE RUST PASS → COLONY TEXT PASS →
  BRAND TYPE PASS → ACTION GRADIENT…), правила с `!important` и хрупкий селектор по значению инлайна
  `.ares-presale [style*="FF2E93"] { display:none !important }`. Нужна консолидация в один осмысленный слой токенов.
- **Стекло, которое надо снять:** `backdrop-filter: blur(14px)` в `.pf-card`, `blur(10px)` в `.glass`,
  `blur(6px)` в шапке фильтров; токены `--pf-glass*`; скругления 12–24px по всему UI.
- **Радужная conic-рамка** `.pf-card--rare` (pink→teal→purple→orange) — неоновый многоцвет, самый «NeuroForge»
  элемент игры (пресейл).
- **Синий/циан прорывается:** кнопка кошелька teal, StatusRow teal, бейдж «твой ордер» `rgba(59,130,246,…)`
  (Tailwind blue), модалка `#1a1a2e`, фокус-ринги `#7CFF6B`.
- **Шрифты:** display = `'Anton'`/`'Archivo Black'`, но `fonts.ts` грузит **только латинские сабсеты** →
  русские заголовки («АГРО-ОТСЕК», «КАЮТА») молча рендерятся Inter'ом, а «трафаретность» имитируется
  `-webkit-text-stroke: 0.6px` (хак «THICK STENCIL PASS»). Для требования «трафарет/конденсед с кириллицей»
  нужен шрифт с кириллическим сабсетом (кандидаты @fontsource: Oswald — конденсед с кириллицей; Tektur,
  Russo One — техно-акциденция; оба с кириллицей — проверить сабсеты при установке). JetBrains Mono уже
  с кириллицей — LCD-стиль показаний сохраняем. Всё локально, без CDN — уже так, сохраняем подход.

## 7. Движение (framer-motion) — что есть

- `Button`: `whileHover scale 1.02 / whileTap 0.96` — generic-масштабирование; **вдавливания нет**,
  `prefers-reduced-motion` не учтён в этом компоненте.
- `AresHullFrame`: пружины latch/pressure + `usePrefersReducedMotion` — **сохраняем как основу** физики.
- `MotionIcon` в навигации — глушители/микродвижение, reduced-motion учтён.
- `TelemetryStrip` — бегущая строка (marquee) — уместна как «бегунок телеметрии», reduced-motion учтён.
- Лидерборд/ордера — stagger-появление y/x; скелетоны — shimmer.
- Ровно требуемое «кнопки-тумблеры вдавливаются, овершут, стрелки, реле» — пока не существует нигде.

## 8. Навигация

`AresBottomNav` — плоская панель из 4 иконок (18px) с 8px-подписями (АГРО/СНАБ/ЖУРНАЛ/КАЮТА) в hull-корпусе.
Пропсы `active: AresTab`, `onChange(tab)` — сохраняем. Требуемый «пульт с клавишами» (клавиша-тумблер с ходом,
защёлкивающаяся в нажатом состоянии, лампой-индикатором) строится на базе `AresHullFrame`-пружин.

## 9. Что уже «своё» и стоит сохранить (не изобретать заново)

- `AresHullFrame`: пружинная физика, visibility-менеджмент, reduced-motion — фундамент плит.
- `GrainOverlay` (feTurbulence, 5 %, overlay) — зерно уже есть, глобальное.
- `DomeFrame` + фазы сола (dawn/day/blueset/night), ParallaxBackground, видео-купол — фон, не трогаем.
- `RollingNumber`/`AnimatedNumber` — приборная механика цифр.
- `LiquidBar` — «ржавая вода» уже в палитре; usar как единственный прогресс-бар.
- `Tuber9` (маскот с 4 настроениями + пасхалка) — готовый носитель голоса для пустых состояний.
- Подход локальных шрифтов `fonts.ts` (@fontsource) — расширяем, не ломаем.

## 10. Расхождение с NeuroForge: чек «убрав цвет и размыв»

Сейчас при обесцвечивании силуэт игры = скруглённые стеклянные карточки 12–24px с blur — совпадает с NeuroForge.
План делает силуэт **прямоугольным с фасками** (clip-path 9-slice), с явной одной тяжёлой плитой на экран,
штампованными швами и болтами только там, где есть функция, — силуэты перестанут совпадать до цвета.
