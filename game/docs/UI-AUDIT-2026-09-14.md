   для миграции inline-стилей без сырых hex.

   `Spinner`, `LoadingState` (скелетоны + подпись), `ErrorState`

   SolanaContext (MainScreen — через InitStatus).
4. **Медиа-запросы**: контейнер уже мобайл-first (max-width 480, safe-area);
