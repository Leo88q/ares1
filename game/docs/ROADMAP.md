# Roadmap — 6 месяцев

Отсчёт от завершения аудита (сентябрь 2026). Каждый пункт помечен слоем: **P** — программа (требует redeploy), **B** — backend, **W** — web, **O** — операционка/маркетинг.

- [x] Единый RPC-поллер на фронте, backoff на 429, code splitting, ErrorBoundary — **W**
- [x] Backend как Express-сервис: on-chain config + epoch-roller, rate limit — **B** (раньше — серверная верификация квестов и привязка Telegram ↔ кошелёк; TG-кран и бот **удалены 14.09.2026**, квесты теперь on-chain `claim_achievement`)
- [x] Тесты: 13 unit (cargo) + интеграционные сценарии `anchor test`, CI на GitHub Actions — **O**
- [x] Redeploy на devnet (04.09.2026, слот 493194605); существующий mint/GameConfig совместимы, `init-onchain` не потребовался — **O**
- [ ] Подключить платный RPC (Helius/Triton) для фронта и бэкенда — **O**

## M2 · Экономика v2 (ноябрь)

- [ ] Динамический `base_yield`: backend-крон корректирует по правилу `burn/mint < 0.5 → −10 %`, `> 0.8 → +5 %` в пределах 3–8 🥔/день — **B**
- [ ] Per-field дневной кап вместо «кто первый» при исчерпании эпохи (защита от снайпинга в момент roll_epoch) — **P**
- [ ] Сезон 1: ограниченный тип поля (тираж 1 000) с уникальным множителем, сезонный лидерборд с призом из treasury — **P/B/W**
- [ ] Стейкинг 🥔 → скидка на налог (sink с удержанием) — **P**
- [ ] Order book v2: частичное исполнение ордеров, покупка за 🥔 (bid-ордера) — **P/W**

## Технический долг, который держим на радаре

| Что | Почему важно | Когда |
|---|---|---|
| JSON-файл как хранилище наград | Не переживёт 2 реплики бэкенда | M1 (SQLite/Postgres вместе с индексером) |
| `getProgramAccounts` для лидерборда | При > 50 k полей начнёт упираться в лимиты RPC | M1 (индексер) |
| Progressive fee обходится дроблением ордеров | Комиссия де-факто плоская 3 % | M2 (order book v2 — комиссия по адресу за 24 ч) |
| Один authority-ключ на сервере | Компрометация сервера = компрометация игры | M0 (Squads + отдельный «reward signer» с делегированным правом) |
| Field PDA без owner в seeds | Нельзя дёшево найти «поля игрока» без memcmp | Решается индексером |
